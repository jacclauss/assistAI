# Privacy policy

AssistAI is a private household assistant for two people. It is not offered to the public.

If you connect Gmail, the assistant can read mail, apply labels, archive messages, and create drafts. It does not send mail, and it does not permanently delete mail.

The sign-in token for each person is stored on a computer in the household. When you ask about a message, the text needed to answer is sent to Fireworks AI. Mail is not sold, and it is not shared with advertisers.

To ask a question or to remove a stored sign-in, use the support email shown on the Google consent screen.
