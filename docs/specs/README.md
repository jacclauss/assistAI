# Specs

One file per build phase: `NNN-short-name.md`, numbered after the last phase
in [architecture.md](../architecture.md) (the original build ended at 13).
Start from [TEMPLATE.md](TEMPLATE.md).

A spec is ready to build when every acceptance criterion can be checked by a
test, an eval case, or a named manual step. Status lives at the top of the
file: `draft`, `ready`, `building`, `done`.
